Musefish Studio

ComfyUI-Musefish-Nodes 插件的本地客户端，开箱即用，无需打开 ComfyUI 网页端。

功能：PiD 图片/视频超分 · DLSS5 图片/视频增强 · UniverSR 音频超分 · 视频下载 （通用平台 + 微信视频号）
结构：客户端 → 本地工作台服务(:17995) → headless 推理引擎(:17996)
模型：从工作台 data/models/ 统一读取，支持链接映射（零拷贝）或真实文件两种部署
要求：NVIDIA RTX 50 系显卡（DLSS5 需要），驱动支持 NGX/D3D12
